Automated Two-Way Google Apps Script Webhook

To enable instant automatic push notifications from your Google Spreadsheet to this dashboard whenever someone edits the sheet in Google Drive, paste this script into Extensions > Apps Script in your Google Sheet: 

function onEdit(e) {
  var sheet = e.source.getActiveSheet();
  if (sheet.getName() === "COLONIES") {
    var payload = {
      event: "COLONY_UPDATED",
      timestamp: new Date().toISOString(),
      updatedRange: e.range.getA1Notation()
    };
    Logger.log("Live Sync triggered: " + JSON.stringify(payload));
  }
}
