60-Second Setup to Enable Live Excel Write-Back

  1. Open your Google Sheet: GHMC COLONIES Sheet.
  2. Click Extensions → Apps Script from the top menu.
  3. Replace any code in Code.gs with the script below (also saved in google-apps-script/Code.gs inside your project ZIP).
  4. Click Save, then click Deploy → New deployment → Web app.
  5. Set Execute as: Me and Who has access: Anyone, then click Deploy.
  6. Copy the Web app URL (ending with /exec), paste it in the box above, and click Test & Connect!
